# Payment Automation

## Overview

This workflow automates the process of syncing payment data from Zoho Billing to Oracle NetSuite using n8n.

The goal of this automation is to reduce manual payment posting, improve finance reconciliation, and keep payment records aligned between Zoho Billing and NetSuite.

## Business Purpose

Finance teams often receive or record customer payments in Zoho Billing while using NetSuite as the main accounting or ERP system.

Without automation, payment details may need to be manually entered into NetSuite. This can create delays, duplicate work, and reconciliation issues.

This workflow helps automate payment movement from Zoho Billing to NetSuite.
